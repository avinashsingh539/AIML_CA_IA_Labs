# Practical Assignment 1.1 – Simple Reflex Agent

## Aim
Implement a simple reflex agent for a floor-cleaning task and describe its environment using PEAS.

## Program
`simple_reflex_vacuum_agent.py` creates a random 3 × 3 floor (`0 = clean`, `1 = dirty`). The agent cleans a dirty tile and follows a zig-zag path across the floor.

It reports the number of tiles cleaned, movement steps, total actions and whether the floor is clean at the end.
